Brake Pedal

April 2026

Description

A custom built brake pedal for the VR Braking Simulation project, using the Meta Quest 3 controller as input. By implementing a spring mechanism, combined with a bell crank and needed safeties, the pedal is able to convert a foot pressing motion into the linear motion needed to trigger the Quest 3 input button. Stress tested to ensure reliability and safety.
